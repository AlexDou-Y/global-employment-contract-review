# Country Rule Template

Create or update a country rule card when reviewing a jurisdiction repeatedly. Keep rules source-backed and mark unresolved points.

## Rule Card Fields

| Field | Description |
|---|---|
| Country / Region | Use official jurisdiction name where known |
| Last Updated | Date the rule card was last checked |
| Official Sources Checked | Laws, ministry pages, regulator pages, immigration/tax/social security pages |
| Employment Models Covered | Local direct hire, EOR, expatriate, contractor, intern, fixed-term |
| Mandatory Contract Contents | Required written particulars or contract terms |
| Contract Type Rules | Fixed-term, indefinite, probation, renewal, language, filing |
| Wage and Payroll Rules | Minimum wage, pay frequency, currency, payslip, deductions |
| Working Time / Overtime | Hours, rest, overtime approval/pay, exemptions |
| Leave / Benefits | Annual leave, sick leave, public holidays, maternity/paternity, statutory benefits |
| Social Security / Tax | Employer registration, withholding, contribution, payroll obligations |
| Visa / Work Authorization | Right-to-work checks, work permit conditions, employer duties |
| Termination / Severance | Notice, cause, procedure, severance, final pay |
| Restrictive Covenants | Non-compete, non-solicit, compensation, duration, scope |
| Confidentiality / IP / Data | Enforceability notes and mandatory privacy requirements |
| Employer-Unfavorable Watchouts | Clauses commonly seen in templates that exceed law or hurt employer flexibility |
| Open Questions | Items requiring Legal/local counsel/vendor confirmation |

## Storage Recommendation

If the skill is expanded later, store reusable country cards as:

`references/country-rules/<country-or-region>.md`

Do not add unsupported rules. A short, verified rule card is better than a long unsourced one.
